# 🌳 Generator GENDEX dla Webtrees
Prosty, ale potężny moduł dla [Webtrees 2.2.x](https://webtrees.net), który automatycznie generuje plik `GENDEX.txt` dla Twojego drzewa genealogicznego. Idealny dla stron genealogicznych, które chcą być kompatybilne z wyszukiwarkami GENDEX, zachowując jednocześnie kontrolę nad swoimi danymi, bez konieczności udostępniania całego pliku GEDCOM osobom trzecim.

Więcej o [GENDEX](https://pl.wikipedia.org/wiki/GENDEX).

## 📥 Instalacja
1. **Pobierz** najnowszy plik [Webtrees-GendexGenerator.zip](https://codeberg.org/Joppla/Webtrees-GendexGenerator/raw/branch/main/Webtrees-GendexGenerator-latest.zip).
2. **Wypakuj** plik.
3. **Umieść** folder `gendex-generator` w katalogu `modules_v4` swojej instalacji Webtrees.
```
/webtrees/
├── modules_v4/
│   └── gendex-generator/  <-- Plaats hier de uitgepakte map
```
4. **Aktywuj** moduł w Webtrees:
- Przejdź do **Panel sterowania > Moduły > Wszystkie moduły**.
- Znajdź **Gendex Generator** i włącz go.

## 🛠 Użycie
Przejdź do **Panelu sterowania** i kliknij w **Moduły > Różne > Generator GENDEX**. Dostosuj ustawienia według swoich preferencji i kliknij **Generuj Gendex**.

## 📌 Wymagania
- Webtrees 2.2.x
- PHP 7.4 lub nowszy
