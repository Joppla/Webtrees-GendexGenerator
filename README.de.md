# 🌳 Webtrees GENDEX-Generator
Ein einfaches, aber leistungsstarkes Modul für [Webtrees 2.2.x](https://webtrees.net), das automatisch eine `GENDEX.txt`-Datei für Ihren Stammbaum generiert. Ideal für genealogische Websites, die mit GENDEX-Suchmaschinen kompatibel sein und gleichzeitig die Kontrolle über ihre Daten behalten möchten, ohne ihre gesamte GEDCOM-Datei mit Dritten teilen zu müssen.

Mehr über [GENDEX](https://de.wikipedia.org/wiki/GENDEX) erfahren.

## 📥 Installation
1. **Laden Sie** die neueste [Webtrees-GendexGenerator.zip](https://codeberg.org/Joppla/Webtrees-GendexGenerator/raw/branch/main/Webtrees-GendexGenerator-latest.zip)-Datei herunter.
2. **Entpacken Sie** die Datei.
3. **Platzieren Sie** den Ordner `gendex-generator` im `modules_v4`-Verzeichnis Ihrer Webtrees-Installation.
```
/webtrees/
├── modules_v4/
│   └── gendex-generator/  <-- Plaats hier de uitgepakte map
```
4. **Aktivieren Sie** das Modul in Webtrees:
- Gehen Sie zu **Kontrollzentrum > Module > Alle Module**.
- Suchen Sie nach **Gendex Generator** und aktivieren Sie es.

## 🛠 Verwendung
Gehen Sie zum **Kontrollzentrum** und klicken Sie unter **Module > Sonstiges** auf **Gendex Generator**. Passen Sie die Einstellungen nach Ihren Wünschen an und klicken Sie auf **Gendex generieren**.

## 📌 Voraussetzungen
- Webtrees 2.2.x
- PHP 7.4 oder höher
