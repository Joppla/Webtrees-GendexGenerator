# 🌳 Webtrees GENDEX Generator
A simple yet powerful module for [Webtrees 2.2.x](https://webtrees.net) that automatically generates a `GENDEX.txt` file for your family tree. Ideal for genealogical websites that want to be compatible with GENDEX search engines while retaining control over their data, without having to share their entire GEDCOM file with third parties.

Learn more about [GENDEX](https://en.wikipedia.org/wiki/GENDEX).

## 📥 Installation
1. **Download** the latest [Webtrees-GendexGenerator.zip](https://codeberg.org/Joppla/Webtrees-GendexGenerator/raw/branch/main/Webtrees-GendexGenerator-latest.zip) file.
2. **Unzip** the file.
3. **Place** the `gendex-generator` folder in the `modules_v4` directory of your Webtrees installation.
```
/webtrees/
├── modules_v4/
│   └── gendex-generator/  <-- Plaats hier de uitgepakte map
```
4. **Enable** the module in Webtrees:
- Go to **Control Panel > Modules > All modules**.
- Find **Gendex Generator** and enable it.

## 🛠 Usage
Go to the **Control Panel** and click on **Modules > Miscellaneous > Gendex Generator**. Adjust the settings to your preference and click **Generate Gendex**.

## 📌 Requirements
- Webtrees 2.2.x
- PHP 7.4 or higher
