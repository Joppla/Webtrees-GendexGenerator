# 🌳 Générateur GENDEX pour Webtrees
Un module simple mais puissant pour [Webtrees 2.2.x](https://webtrees.net) qui génère automatiquement un fichier `GENDEX.txt` pour votre arbre généalogique. Idéal pour les sites généalogiques souhaitant être compatibles avec les moteurs de recherche GENDEX tout en gardant le contrôle sur leurs données, sans avoir à partager leur fichier GEDCOM entier avec des tiers.

En savoir plus sur [GENDEX](https://fr.wikipedia.org/wiki/GENDEX).

## 📥 Installation
1. **Téléchargez** le dernier fichier [Webtrees-GendexGenerator.zip](https://codeberg.org/Joppla/Webtrees-GendexGenerator/raw/branch/main/Webtrees-GendexGenerator-latest.zip).
2. **Décompressez** le fichier.
3. **Placez** le dossier `gendex-generator` dans le répertoire `modules_v4` de votre installation Webtrees.
```
/webtrees/
├── modules_v4/
│   └── gendex-generator/  <-- Plaats hier de uitgepakte map
```
4. **Activez** le module dans Webtrees :
- Allez dans **Panneau de contrôle > Modules > Tous les modules**.
- Trouvez **Gendex Generator** et activez-le.

## 🛠 Utilisation
Allez dans le **Panneau de contrôle** et cliquez sur **Modules > Divers > Générateur GENDEX**. Ajustez les paramètres selon vos préférences et cliquez sur **Générer Gendex**.

## 📌 Prérequis
- Webtrees 2.2.x
- PHP 7.4 ou supérieur
